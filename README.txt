KAYVORAX FILMS — Website files

Files:
- index.html: website homepage
- kayvorax-logo.jpg: your uploaded logo/banner image

To publish for free:
1. Upload these two files to a GitHub repository.
2. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
3. GitHub will provide your public website address.

Before publishing, replace the # links in index.html with your real YouTube, Facebook and TikTok page URLs, and add video links/contact details.
